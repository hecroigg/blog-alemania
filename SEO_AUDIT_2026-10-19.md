- 34 discovered, not yet crawled; 6 crawled, not indexed; 22 HTTP 404 reported; 3 redirect URLs; 8 deliberately excluded by noindex **need URL-by-URL confirmation**.

## What this branch changes
- Home guide index now links to /es/guides, /de/guides and /fr/guides with actual HTML anchor links.
- Added `google-adsense-account` metadata to support ownership verification independent of advertising consent.
- Removed unconditional AdSense JavaScript from the page head. Loading is now conditional on the visitor's advertising preference.
- Made the site's privacy preference panel accessible again after the first decision.

## Existing code that was checked
- `app/robots.ts` permits public pages and provides the canonical sitemap.
- `app/sitemap.ts` emits core pages, editorial guides, available languages and cities.
- SEO-focused pages already emit their own canonical URLs.
- `public/ads.txt` lists Google publisher `pub-8337311370258201` correctly.
- `/search` is intentionally `noindex`; localized guide indexes for non-search locales are also intentionally noindexed. Do not indiscriminately remove those directives.
- `proxy.ts` attempts to normalize malformed crawler suffixes with a 301, but its behavior on the live Cloudflare/vinext worker must be independently verified.

## New live Cloudflare WAF findings (19 Oct 2026, 10:40 UTC)
A GitHub-hosted read-only HTTP crawl found:
- `/robots.txt` returns 200 and correctly lists the sitemap.
- `/ads.txt` returns 200 with the correct AdSense publisher.
- `/sitemap.xml` returns **403**, `cf-mitigated: challenge` and title **Just a moment...**, even for multiple tested User-Agent strings (custom, browser, spoofed Googlebot); this is **not** a normal XML response for the tested clients.
- Some requests to `/cities/berlin` and `/cities/cologne` also return a Cloudflare challenge, while another custom UA occasionally gets 200. `/authorities` browser and spoofed bot UAs were also challenged.
- This proves Cloudflare is sometimes challenging generic HTTP crawlers. It **does not prove genuine Googlebot is blocked**, since user agent text can be spoofed and Cloudflare may allow Google verified bot IPs.
- Example CF Ray IDs: `a4cf299db9d18c9d-IAD` (`/sitemap.xml`), `a4cf299f1bb15d21-IAD` (`/cities/berlin`).
